# 政府韧性信息测量研究 · Git研究档案

本仓库用于版本化管理“中国地方政府公开文本中的韧性信息测量”的研究流程、标注规则、试点数据、复核协议与复现说明。项目以武汉市为试点，后续拟构建地区×时间韧性信息指标。

> 研究对象是政府公开文本**传达的韧性信息**，而非直接测量政府实际韧性或政策落实效果。

## 当前归档状态（2026-11-22）
- 2026-11-19 开题材料及研究讨论已整理。
- 手册目前可核实原件为 **V1.2** 和 **V1.3.1**。试标数据注明使用 **V1.3.2**，但该手册原件仍待归档。
- 武汉政府公文首批试标：17篇公文索引，160条AI机器预标注，其中15篇有片段、对应13个划分组。
- 难例人工复核候选38条、随机审计盲表26条；截至归档时人工复核栏均未填写。
- 目前缺少完整网页快照、采集程序、AI提示词及V1.3.2手册，故尚不能完全重跑整个采集—标注过程。

## 研究工作流
```text
武汉政府公开公文 → 来源归属核实、去重、清洗与切分
→ AI初始预标注（weak） → 难例优先与随机盲审（gold）
→ 按文档/转载近重复组划分训练、验证、测试
→ 词典基线与中文BERT多标签分类比较
→ 单篇公文量化 → 地区×时间面板及效度检验
```

## 安全与数据原则
仓库设为 Private。禁止提交密钥、账号、出版商受限PDF、未获授权的第三方原文全文。机器标签必须标记 `weak`，已核实人工标签才可标记 `gold`。目前尚未训练或验证BERT，不得将AI预标注的正例数量当作准确率；已抽样片段也不能直接作为整篇公文的总体占比。

**注意：** GitHub中的提交发生于归档/上传日期；历史研究活动日期单列在PROCESS_LOG中。不伪造早期Git提交。
