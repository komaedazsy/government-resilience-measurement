## ID与来源字段
- `文档ID`：对应原始文件，例如WH-2388280。
- `片段ID`：对应自然段或政策条款，例如WH-2388280-P0058。
- `文档组`、`划分组`：用于按文档、近重复组隔离训练集和测试集。
- `来源URL`、`发文机关`、`发布日期`、`网页存档`、`正文快照`：用于溯源；工作表里的本地路径不表示对应原始网页文件已入库。

## AI字段
- `AI_R`、`AI_C`、`AI_A`、`AI_E`：多标签0/1/待判。
- `AI_Core`：R/C/A任一为1→1；三项均0→0；其他缺失→待判。
- `R原文证据及状态主体` 等：AI提供的证据与状态、行动主体建议，未经人工确认。
- `争议标记`、`模型分歧维度`、`AI判断及待核`、`复核路径`：选择复核对象。
- `标签层级`、`标签来源`、`复核状态`：160条均为 `weak` / `ai_preannotation` / `unreviewed`。
- `手册版本`：本批记录1.3.2；本仓库手册原件尚未补齐该版本。
