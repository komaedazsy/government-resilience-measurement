# 复现与数据血缘

## 已归档/已确认
- V1.2、V1.3.1两份方法手册原件在离线Git归档包中；GitHub仅同步其中可读说明时，不可宣称已完成原始DOCX的二进制同步。
- 首批试标Excel确有17篇公文索引、160条AI预标注、38条难例候选。
- 26条随机审计盲表没有模型预测列。
- 表格中的标签属于weak，并非gold。

## 缺失材料
- 真正使用的V1.3.2手册原件、完整提示词和模型参数。
- 原始网页HTML、正文快照及原始采集程序。
- 全量公文的可靠切分与去重输入。
- 人工裁决的gold标签及与文档/近重复组隔离的测试集。
- 中文BERT的训练依赖、配置、权重和独立测试结果。

## 复现工作流
1. 从具有合法来源的武汉政府公文中获得完整正文和元数据，并保存URL、日期、发文机关。
2. 去重并统一段落/条款切分，生成不可变doc_id、unit_id、duplicate_group。
3. 以冻结手册版本和相同提示词生成AI weak初标，记录所用模型、推理日期。
4. 人工先完成不含AI预测的随机盲表，再核验难例；保留原始AI标签与人工终标。
5. 用文档及近重复组划分训练/验证/测试；禁止同一原文件的片段跨集合。
6. 评估时逐维输出有效样本量、Precision、Recall、F1；避免误把难例选择的准确率外推全部语料。
7. 在完整文本覆盖、明确分母、处理跨文种差异后才形成公文与地区×时间韧性信息指数。

## Git归档纪律
对每次新增的手册、原始数据、脚本与训练配置创建独立提交，CHANGELOG记录研究方法改变。远端上传时新创建的GitHub提交与原本离线Git五条提交的SHA可能不同；离线包中的历史须另外保留。
