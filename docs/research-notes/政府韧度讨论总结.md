# 科研课堂笔记

## 一、主题

**利用政府公开文本，量化政府传达的韧性信息，并构建地区—时间面板数据。**

课堂提出的研究设想是：参考已有研究，通过文本识别模型处理政府公文等公开材料，提取韧性相关表达，再按地区和时间汇总为指标，为研究政府韧性与企业创新等问题提供测量工具。

## 二、概念与例子

### 1. 韧性

课堂将韧性概括为三个方面：

| 维度 | 课堂解释 |
|---|---|
| 抵抗力 | 事物经受冲击时的抵抗能力 |
| 恢复力 | 冲击之后恢复的能力 |
| 适应力 | 面对冲击时的适应能力 |

课堂举例包括企业韧性、企业创新韧性、区域韧性和政府韧性。韧性既可以作为需要提升的研究对象，也可以作为影响其他结果的解释因素。

### 2. 政府韧性的测量难点

仅用政府财政收支指标衡量韧性存在局限。课堂举例：一个地区财政收入少，可能源于当地经济条件较弱，不能据此认定其政府缺乏韧性。

因此，课堂提出从政府公开文本中提取韧性信息的思路。需要区分：**文本传达的韧性信息，与政府实际具备的韧性能力，是否可以等同，课堂尚未论证。**

### 3. 科研问题中的 X 与 Y

课堂强调，研究需要找到重要的结果变量，以及具有研究价值的影响因素。

- **Y：需要解释或提升的结果。**例如企业创新、企业韧性、区域韧性。
- **X：可能影响 Y 的因素。**例如资金投入、科研人员投入，以及拟研究的政府韧性。

原文对“自变量、因变量”的称呼有口头混用；按其表达的研究关系，应理解为“通过 X 解释或影响 Y”。

课堂以增加资金、招聘科研人员来促进企业创新为例，说明仅提出常见关系，未必足以形成有亮点的问题。具有价值的变量选择与量化方式，也是研究贡献的来源。

### 4. 面板数据

课堂将面板通俗解释为：记录不同主体在不同时间的某项属性及其数值，整理成一张大表。

本研究设想中的结构是：

**地区 × 时间 → 该地区在该时段传达的韧性信息指标。**

具体采用月度还是其他时间间隔，尚未确定。

## 三、研究思路与参考案例

### 1. 政府文本的来源

课堂以武汉市政府门户网站为例，展示了以下查找思路：

- 浏览信息公开、时政要闻等栏目。
- 搜索领导姓名，查找相关消息和讲话内容。
- 将政府公文及相关公开文本作为潜在研究材料。

文本采集范围尚有两种设想：提取行政官员的讲话，或直接采集整篇公开文本，课堂未作最终选择。

### 2. 参考研究

据课堂介绍，一篇发表于 *Information Systems Research* 的文章：

- 采集美国州长的推特数据；
- 识别其中传达的韧性信息；
- 据此构建美国各州的韧性信息面板。

讲述者表示后续会提供该文章。当前材料没有给出文章题名、作者、年份及具体方法细节。

### 3. 拟议技术流程

1. 收集政府公文等公开文本。
2. 依据韧性量表或相应判定标准，识别韧性相关文字。
3. 对单篇文本传达的韧性信息进行量化。
4. 按地区和时间段汇总，形成地区韧性信息指数。
5. 进一步构建全国范围的面板数据。

课堂以“出现多少次”“一个月的信息加在一起”说明量化与汇总思路，但尚未给出正式计算公式。

### 4. 模型选择

课堂提到 BERT，并提出训练或微调一个能够在本地部署的专门文本模型。

选择本地模型的主要考虑是：全国范围的文本处理量较大，直接使用大语言模型会产生较高的 token 成本。

课堂口头提及模型可能约为三四 GB，但具体模型、体积和设备要求均未确定。

## 四、重点

- **研究切入点：**政府韧性的文本量化。课堂认为，相较企业层面的韧性研究，政府层面的测量仍有较大探索空间；这属于课堂判断，尚未提供文献综述支持。
- **近期核心难点：**得到能够较好识别韧性表达的模型。
- **研究方法要求：**参考已有高水平研究，在已有方法基础上推进创新。
- **长期目标：**形成全国地区层面的韧性信息面板，而非只分析一篇公文。
- **近期交付重点：**先实现单篇文本的输入与量化输出，并说明自己的研究思路。

## 五、作业与交付要求

**期限：一周内。**

明确提出的交付包括：

1. **一个可运行的模型或工具。**输入一篇推文或政府公文后，能够输出其中传达的韧性信息量化结果；课堂要求模型在本地部署。
2. **一份报告。**说明工作与思路，允许借助 AI 完成，形式不作严格限制。

课堂没有要求一周内完成全国数据采集与完整面板，也没有明确报告字数、格式、模型准确率或评分标准。

## 六、待确认问题

- 参考文章的完整信息、原文及可复用的方法是什么？
- 韧性量表如何定义？是否直接采用抵抗力、恢复力、适应力三个维度？
- 测量目标是“政府传达的韧性信息”，还是进一步将其作为政府实际韧性的代理指标？
- 数据范围包括哪些栏目、文种和行政层级？采用整篇文本还是官员讲话？
- 模型输出采用次数、分类结果、分维度得分，还是其他指标？
- 地区—时间指标如何汇总，是否需要考虑文本篇数和长度的差异？
- 模型如何标注训练数据、评价识别效果？一周交付的具体验收标准是什么？
- 全国面板的地区范围、起止年份和时间粒度如何确定？
